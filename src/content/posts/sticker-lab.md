这篇不是“设计方案”，是一份踩坑流水账。

贴纸这件事前后折腾了好几天：引擎从官网拖下来本地化、遮挡层做了又拆、重锚改了三版、测试页建了七个又全删掉。最后留在首页里的东西其实不多，但每一行都是真机上一帧一帧盯出来的——顺便，烧掉的 token 大概够喝一个月奶茶。

下面按当时的试验顺序记，每一套都写了怎么做的、原以为会怎样、实际怎样、最后有没有留下。

## A · CSS 滚动驱动动画

**实现原理**：贴纸层固定定位，用 `animation-timeline: scroll(root)` 让整层跟着滚动平移，位移交给合成器，JS 不参与逐帧移动；指针坐标在交给引擎前补回滚动偏移，不然撕开的落点会整体偏。

**预计效果**：这是理论上最干净的做法——浏览器自己算滚动，贴纸应该和文字严丝合缝。

**实际表现**：Chrome、Via、QQ、Win11 Edge 上确实几乎察觉不到抖动，是唯一一个“看着像长在页面上”的方案。但安卓 Edge 在工具栏第一次出现时会跳一下，查下来是视口高度变了、中心跟着挪了半个差值，补上 `ΔH/2` 之后才老实；另外滚动范围要用 `scrollHeight - clientHeight`，用 `innerHeight` 会在工具栏出现后产生速度差。

**最后取用状态**：**采用**，作为首页默认。Safari 上没有这个能力，只能回退到 E。

## B · rAF + transform

**实现原理**：监听 scroll，在 `requestAnimationFrame` 里读 `scrollY`，用 CSS transform 平移渲染层，同样补指针偏移。

**预计效果**：不重绘 WebGL，只写一次 transform，应该比逐帧改贴纸坐标省得多，至少在安卓上能追平 A。

**实际表现**：安卓各浏览器都还有抽搐，Via 上是轻微的“滑移”。原因很朴素——scroll 事件天然晚一帧，惯性滚动时事件又稀疏，rAF 再去追就已经晚了。调过事件合并、调过 transform 的写入时机，收益都很有限；这段大概是最费 token 的一段，改来改去最后承认它是机制问题。

**最后取用状态**：未采用，只在 A 不可用时作为兜底。

## C · 现行 scroll 事件

**实现原理**：最直白的写法，每次 scroll 把贴纸的 y 坐标加上增量，然后让引擎重绘。

**预计效果**：能跟就行，先跑起来再说。

**实际表现**：跟是能跟，但拖影和掉帧都明显，手机上尤其糊。也是从这一步开始意识到“跟随”不能靠每帧改引擎坐标。

**最后取用状态**：未采用。

## D · 现行 scroll，无遮挡层

**实现原理**：滚动方式和 C 一样，只是把按轮廓生成的遮挡层关掉。

**预计效果**：用来验证一件事——手感变差到底是滚动方式的问题，还是遮挡层的问题。

**实际表现**：关掉遮挡层后点击能穿透，但滚动照样抖。结论很明确：手感只跟驱动方式有关，和遮挡层无关；遮挡层可以放心加。

**最后取用状态**：未采用，纯对照。

## E · 不跟随（txt 原始行为）

**实现原理**：完全照 `贴纸效果.txt` 的默认：贴纸钉在视口上，不响应滚动，也不加任何遮挡。

**预计效果**：绝对稳，但贴纸会像贴在屏幕上，滚内容时它不动。

**实际表现**：所有浏览器都稳，iPad Safari 上也正常。代价是贴纸和内容脱钩，长页面滚动时会有“浮在上面”的错觉。不过对 Safari 来说，这是唯一不抖的方案。

**最后取用状态**：**采用**，作为 Safari / 不支持滚动驱动动画时的整页回退；`/sticker-show` 展示页也用它，但额外打开了遮挡层。

## G · 2× 画布

**实现原理**：把引擎画布的缓冲高度设成视口的两倍，同步 `stage.height` 并按新高度重算相机与投影，让上下各多出半个视口的可绘制范围；CSS 把画布改成 `200dvh` 并向上偏移半个视口。

**预计效果**：既然截断是因为画布不够大，那把画布做大不就行了？当时觉得这招能一劳永逸。

**实际表现**：截断确实没了，但相机距离跟着画布高度翻倍，撕开时抬起的那点 3D 弧度被压得很平，像贴纸变薄了；显存和阴影目标也翻倍。为了一个边缘问题牺牲手感，不划算。

**最后取用状态**：未采用。

## H · 提前重锚

**实现原理**：和 A 一样，只把重锚的触发距离从 16px 提到视口的 12%，让画布在贴纸还没贴边时就提前挪过去。

**预计效果**：不动画布尺寸，只改时机，应该能少出现“拖到边缘瞬间缺一块”。

**实际表现**：缺角确实少了，但拖到边缘那一刻仍然可能看不到超出的部分；而且重锚本身会让污渍整体跳一下——后来统一的“先把污渍淡出再重锚”就是在这时候补上的。

**最后取用状态**：未采用。最终方案是 A + 放回贴纸后立刻重锚，重锚前先让污渍淡出。

## 最后留下的

- 滚动跟随：**A**。
- 回退：Safari 或没有滚动驱动动画，整页退回 **E**（不跟随、不屏蔽）。
- 截断：**放回贴纸后立刻竖直重锚**，重锚前等污渍淡出，避免它跳。
- 遮挡：A 下按贴纸轮廓生成透明遮挡层，压住的链接、hover、右键、框选都不响应。
- 参数：`public/stickers/stickers.json`，和图片放在一起；新图暂时手动补参数。

首页现在每次随机一张、随机位置、旋转 ±45°；`/sticker-show` 每次随机三张，页面不能滚动也不能缩放，中间的 `[ReRoll]` 重新抽一次。
