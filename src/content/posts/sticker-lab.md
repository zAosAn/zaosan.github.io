这是贴纸“跟随页面滚动”的三套实现加一个现状对照，用来在手机 / iPad 上比较实际手感。四个页面内容相同（首页的 About、文章列表、页脚），贴纸参数相同（每次随机一张、位置随机、旋转 ±45°），差别只在滚动方式和是否屏蔽点击。

## 四个入口

- [A · CSS 滚动驱动动画](/sticker-test/a/)：由合成器直接驱动平移，理论上最跟手；浏览器不支持滚动动画时会自动回退到 B（右上角会标注）。
- [B · rAF + transform](/sticker-test/b/)：每帧读 `scrollY`，用 CSS transform 平移整个渲染层，不重绘 WebGL。
- [C · 现行 scroll 事件](/sticker-test/c/)：现在的做法（每次 scroll 改贴纸坐标并重绘），但加了遮挡层。
- [D · 现行 scroll，无遮挡层](/sticker-test/d/)：完全等于现在线上的行为，用作对照。

## 每页怎么试

1. 快速上下滑动，看贴纸和文字是否同步，有没有拖影、跳帧，Safari 上特别看滚动刚开始时有没有竖向拉伸。
2. 让浏览器地址栏/工具栏收起再出现，看贴纸位置会不会突然跳一段。
3. 在贴纸边缘按住拖动，应该开始“撕”，松手贴回。
4. 在贴纸中间按住拖动，应该正常滚动页面（不能把页面锁死）。
5. 点贴纸压住的文章链接：A/B/C 应该点不动（被遮挡层接管），D 应该能点（现状）。
6. 撕开一次制造污渍，然后滚动：污渍应该跟着内容滑走，同时 300ms 内淡出。
